# sara-omeilia.github.io

Personal site built with [Astro](https://astro.build/) + [Starlight](https://starlight.astro.build/) and deployed to GitHub Pages by GitHub Actions (`.github/workflows/deploy.yml`).

- Install: `npm install`
- Preview locally: `npm run dev`, then open http://localhost:4321
- New writing sample: add a `.md` or `.mdx` file to `src/content/docs/writing-samples/` (use `.mdx` when it imports components such as `<Steps>`)
- Publish: push to `main`
